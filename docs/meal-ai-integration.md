# AI 餐食接口预留

v0.5.0 的 `MealEstimateProvider` 为模型无关的扩展接口。默认没有配置服务，页面显示“尚未配置”，生成按钮不可用；本地换算、目标计算和手动记餐全部可用。

当前支持的扩展场景是**餐食文字 → 可编辑营养草稿**。图片识别、多轮对话、自动营养建议及训练建议不在此版本实现范围。

## GitHub Pages 接入方式

GitHub Pages 只托管前端静态文件。模型 API Key 保存在自行部署的服务端或边缘代理中，前端构建变量只提供代理地址。

本地复制 `.env.example` 为 `.env.local` 并填写：

```dotenv
VITE_MEAL_AI_ENDPOINT=https://your-proxy.example/meal-estimate
```

GitHub Actions 构建读取仓库公开变量 `MEAL_AI_ENDPOINT`。未设置则禁用 AI；配置后重新构建部署。**不要在任何 VITE 变量、URL 查询参数或本地存储中放模型密钥。** 代理 URL 是公开的，服务端需自行提供访问控制、额度和限流；不能将浏览器 Origin 校验当成身份认证。

代理允许该 Pages 来源的 CORS 及 `POST`、`Content-Type: application/json` 预检。客户端使用 HTTPS，localhost 开发允许 HTTP；禁用跨站凭据、不携带 referrer、不跟随重定向，响应不进入 Service Worker 缓存。当前前端没有账号登录协议，未来需要认证时扩展适配器和服务端合同。

## 请求合同

只在用户明确同意后发送本次手动输入的文字，**不发送整个本地档案、体重、训练、历史餐食或备份**。

```json
{
  "schemaVersion": 1,
  "requestId": "99449812-4c58-41ec-b940-5b7074ea7624",
  "locale": "zh-CN",
  "text": "午餐吃了熟米饭约150克"
}
```

文字 1–2000 字符，未知字段拒绝。客户端等待最多 15 秒，用户可取消。

## 响应合同

下面仅为说明接口的合成样本，不是实际模型结果：

```json
{
  "schemaVersion": 1,
  "requestId": "99449812-4c58-41ec-b940-5b7074ea7624",
  "provider": "自建营养代理",
  "items": [
    {
      "name": "熟米饭",
      "grams": 150,
      "energyPer100g": 116,
      "proteinPer100g": null,
      "carbsPer100g": 25,
      "fatPer100g": null,
      "assumptions": ["按熟重估算，未包含额外食用油"]
    }
  ],
  "warnings": ["请确认实际克重和烹饪方式"]
}
```

返回 `application/json`，完整内容最多 64 KiB，必须回传相同 requestId 和受支持的 schemaVersion。最多二十项食物，克重必须为 0.1–10000 的有限数值并精确到 0.1 克；能量为 0–1000 kcal/100g；三大营养素各为 0–100 g/100g 或 null，已知小计需合理。未知项使用 null，不能编造为零。`assumptions` 和 `warnings` 必须保留实际不确定性，不给伪造的可信度分数或数据库来源。

参考运行时验证：`src/services/meal-ai.ts` 中的 Zod schemas。新模型可实现相同 provider 接口，或由代理把模型输出规范化为该合同。客户端的校验不能替代服务端的输出验证。

## 确认与持久化

返回值首先进入内存草稿，展示来源、假设与警告。用户可以修改名称、克重、每百克营养、归属日期和餐次。修改后需要重新勾选检查确认，再显式保存。

保存由一个本地事务同时写入新食物与带快照的餐食。失败全部回滚，未确认不入库；备注保留 AI 估算标记、服务名称及原始假设。保存后当天饮食仍为部分记录，必须由用户另外确认全天是否记全。未知营养保持 null，摄入由本地统一计算函数重新计算，不直接信任 AI 给出的总热量。

业务 schema 和备份格式仍为版本一。API Key、AI 服务配置和请求中的描述不写入业务备份；确认保存的餐食及假设会随正常日志备份。

## 已验证边界

- 未配置、未同意、输入含额外档案字段时不发出请求。
- 拒绝不安全 URL、URL 凭据、查询参数、未知版本、错误 requestId、非法数值、超大响应与非 JSON。
- 超时/取消可恢复到手动记录，结果不自动入账。
- 测试提供者与本地数据库验证人工修改后再保存、未知营养保留及事务回滚。

当前尚未对接实际外部 AI 服务，没有进行线上模型质量验证。
