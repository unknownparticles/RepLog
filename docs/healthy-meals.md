# 健身食物与健康组合餐

饮食页可进入「食物库」与「健康组合餐」，健身食谱页和热量计算的 AI 草稿页也提供组合入口。全部登记、文字匹配、计算和组合保存可离线使用，不需要模型服务或网络请求。

## 食物登记

食物库的「健身食物参考目录」包含 39 种通用食物与 2 类补剂入口：

- 蔬菜：胡萝卜、西兰花、菠菜、黄瓜、番茄、生菜、白菜、菜花、白蘑菇、甜椒。
- 水果：苹果、香蕉、橙子、猕猴桃、草莓、蓝莓、梨。
- 肉蛋鱼虾：去皮鸡胸肉、瘦牛肉、猪里脊、虾仁、鲈鱼、三文鱼、鸡蛋、蛋清。
- 奶豆：纯牛奶、原味无糖酸奶、北豆腐、毛豆仁。
- 主食：燕麦片、熟米饭、熟糙米饭、土豆、红薯、干荞麦面。
- 调味：盐、植物油、芝麻油、生抽。
- 补剂：蛋白粉、增肌粉。无内置热量，必须填写实际产品标签。

通用值按每百克可食部分估算，由项目维护，并非经过实验室检测的成分库。肉类和蔬菜默认可食生重，鸡蛋去壳、鱼去骨、虾去壳；面和燕麦按干重，米饭/糙米饭明确按熟重，水果去除不可食部分。具体包装食品优先修改为实际标签。目录并非“健身专属食物”清单，重点是方便选择各类食物并控制份量。

可以逐项查看并登记，也可确认登记当前分类的通用食物。目录不自动写入个人食物库；已存在同名或相同目录标识的条目（含归档）不覆盖、不重新创建。用户的个人修改和历史快照保持原样。

补剂不批量登记。按标签登记时能量字段为空，填写品牌/口味、每百克营养、份量名称和克重。例如将一勺登记为 30 克，匹配“甲牌蛋白粉1勺”才可换算。增肌粉与蛋白粉分别登记，绝不按同一热量处理。盐有已知零热量，也能登记和计量；零热量不代表钠含量为零。

## 从已有食物搭配

健康组合餐可手动搜索选择已登记食物、调整数量，也可输入文字匹配后逐项确认。保存组合只保存名称和一份的食物引用/克重，不计入饮食；载入时使用食物库最新标签值并展示总热量与三大营养素。归档或缺失条目会提示重新选择，未知营养显示“仅已知小计”。

按归属日期、餐次与食用份数确认后，才写入独立餐食。记录保留确认时的营养快照，后续修改食物标签不会改变历史。组合支持编辑、删除，完整备份包含组合。

## 仅匹配已登记食物

本地匹配是名称/别名与数量规则，不调用语言模型，不猜测新食物的热量。例：

```text
胡萝卜100克，西兰花150克，甲牌蛋白粉1勺，甲牌增肌粉0.5份，盐2克
```

支持中文/英文克与千克、已登记的份/勺/杯/碗；数字支持小数。多个条目用逗号、顿号、分号、加号或换行分开，括号内的顿号不会拆开食物名。胡萝卜/红萝卜、番茄/西红柿等明确别名可以匹配。

只有唯一的精确名称或明确别名自动选中。部分名称、同名多条、不同品牌和生熟差异需要在下拉框选择具体登记条目。未知食物不创建、不使用参考目录值兜底、不视为零；没有数量、无克重的勺/碗、负数或非法范围会阻止计算与入账。可以补全、移除该行，或先回食物库登记。

每份最多五十个条目，克重舍入到 0.1 克；食用份数 0.1–10，最多一位小数；换算后每项须在 0.1–10000 克范围内。预览与入账使用同样的舍入克重。提交事务重新检查食物是否存在、归档及修订版本，预览后标签变化时要求重新确认。

例如在用户登记胡萝卜 41 千卡/100克、西兰花 34、甲牌蛋白粉 400（一勺30克）、甲牌增肌粉 380（一份50克）、盐 0 后，上例总能量为 `41 + 51 + 120 + 95 + 0 = 307` 千卡。补剂数值仅为本例输入，不是内置推荐值。

## 搭配参考与来源

提供鸡胸蔬菜米饭餐、牛肉彩蔬糙米餐、燕麦奶蛋水果早餐、豆腐蔬菜红薯餐四种本项目编写的搭配示例。选中后仍只匹配已登记食物，缺失食材会保留待确认行；烹调油、盐和额外酱汁按实际使用添加。

2026 年 10 月 21 日核对：

- [NHS Eatwell Guide](https://www.nhs.uk/live-well/eat-well/food-guidelines-and-food-labels/the-eatwell-guide/)：选择多样蔬果、较高纤维主食、豆鱼蛋肉、奶及替代品，植物油少量使用。
- [ISSN protein and exercise（2017）](https://pmc.ncbi.nlm.nih.gov/articles/PMC5477153/)：说明运动人群蛋白质摄入和食物/补剂来源，提及一般运动者每日 1.4–2.0 克/千克及每次 20–40 克的常见范围。本功能不自动套用该范围设置个人目标。
- 既有 [HowToCook 健身适用菜谱](fitness-recipes.md)继续提供制作步骤与来源，使用自己的通用估算标记。健康组合餐与其分别显示数据依据。

以上是搭配原则来源，不是食物成分数值来源；未复制外站食谱、图片或引入需密钥的营养接口。

## 数据与验证

数据库模式及备份格式升至二，增加 `mealCombos`，旧版本一数据库无损增加该表，版本一备份转换为含空组合列表的新版数据。新备份校验组合食物引用、标识和克重。恢复后旧页面不能继续写入。备份导入或餐食写入失败保持事务前数据。

运行 `npm test`、`npm run build`、`npx playwright test tests/e2e/healthy-meals.spec.ts`。用例涵盖通用目录、补剂无默认值、登记保留修改、匹配歧义/生熟/未知单位、盐已知零、未知营养、份量舍入、更新标签与历史、旧库迁移、两代备份、回滚，以及手机离线登记/匹配/组合入账。
