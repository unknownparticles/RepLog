# 动作示范

v0.3.0 接入 29 个可核对的真人动作视频。动作库展示海报，并支持“仅有示范”筛选；打开动作详情后主动播放。训练中的对应动作提供“查看示范”入口，未匹配动作继续提供文字说明。

播放器支持暂停、循环、0.5 倍慢放、正常和 1.5 倍速，以及手机内联播放。默认不自动播放；开启减少动态效果时默认关闭循环。视频没有音轨，文字说明独立可读。

## 素材来源与许可

所有片段原作者为 **Goulart**，来自 [wger](https://wger.de)，逐项视频条目标注 **[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)**。本项目保留作者、来源、许可链接与修改说明；视频及衍生海报继续采用该许可。

- [来源与动作映射](../resources/exercise-media-sources.json)：本地动作标识、原始视频地址、wger 标识、原始大小和核对日期。
- [发布清单](../public/media/exercises/manifest.json)：压缩文件、时长、尺寸、体积与 SHA-256。
- [完整署名](../public/media/exercises/ATTRIBUTION.md)：逐个素材的来源与许可。

处理方式为去除音轨、等比缩放至最长边 480 像素、20 fps、保留最多 12 秒，编码为 H.264 MP4 并生成 JPEG 海报。发布素材合计约 9.5 MiB，原始大视频不进入仓库。

坐姿、窄握、曲杆等变式在播放器旁明确说明。wger 的普通/辅助引体条目指向相同片段，画面未清楚展示辅助方式，本轮排除这两项，避免错误配对。自建动作不会因为名称相似而自动绑定视频。

## 离线使用

示范按需下载，不参与应用壳的全量预缓存。播放时仅访问站点自身资源，不调用远程 API，不需要密钥。

点击“保存供离线”后，应用下载完整视频和海报，验证文件大小及 SHA-256，再写入当前站点独立的缓存。成功后显示“已保存，可离线播放”；支持移除下载。核心离线可用状态不代表所有示范都已经下载。

离线重开时优先从缓存创建本地媒体地址；Service Worker 同时支持已缓存视频的 Range 分段请求。下载失败、存储不足和媒体加载失败均提供提示，文字说明和训练记录保持可用。

媒体缓存不包含个人记录，不进入 JSON 业务备份。换设备后可重新下载公开示范；浏览器清理站点数据时，离线视频也可能被清除。

## 重新生成素材

需要 Python 3、curl、ffmpeg 和 ffprobe：

```sh
python3 scripts/prepare-exercise-media.py
```

脚本只接受已核验的 wger CC BY-SA 4.0 来源，原片写入系统临时目录，发布文件写入 public/media/exercises。也可用 `--only builtin-001` 重建单项。新增映射前应核对器械、动作姿态和素材条目的独立许可。

单元测试核对所有发布文件的哈希、大小、稳定标识和唯一映射。浏览器测试验证实际播放、慢放、完整下载、断网重开、Range 请求和错误回退。
