# 页面加载与触屏输入

页面使用独立脚本分块，日历入口不加载训练动作线稿、动作视频清单、设置、热量计算或图表页面模块。应用上下文与弹窗组件分离，记录元数据与表单校验模块分离，使启动入口不依赖整套表单组件和校验逻辑。按当前生产构建，入口脚本由约 867 KB（压缩传输约 275 KB）降至约 478 KB（压缩传输约 154 KB）。这是入口文件大小，完整日历仍需要其页面和公共模块；不代表总下载量或实测加载时间同比下降。

动作库与训练选择器默认静态显示，每批渲染 24 个动作，点击加载更多继续显示；搜索和筛选覆盖完整目录。120 个动作的初始行数减少至原来的五分之一。可手动开启动画，静态缩略图不创建动画观察器或注册相关事件监听，组件通过记忆化减少重复渲染。

离线资源继续预缓存所有页面脚本，保证首次离线准备完成后可以断网打开尚未访问的页面。因此完整安装缓存的总体积基本不变。约 11 MB 的真人视频与海报仍由用户按需加载，不在启动时自动下载。

iOS 会在聚焦字号小于 16px 的编辑控件时自动放大。触屏设备（含横屏与平板）及窄屏统一将输入框、选择框和多行文本的字号设为 16px，以足够的样式优先级覆盖组件原有的 12–13px 字号；保留用户手动缩放。

验证覆盖旧目录升级、全部动作线稿、分批加载和完整搜索、页面脚本按需加载、未访问页面断网使用，以及 390、844、1024 像素触屏视口中的表单、视频速度、动作筛选和训练组次控件。浏览器模拟检查最终字号与操作流程，iPhone 系统键盘和自动缩放行为仍需真机确认。
