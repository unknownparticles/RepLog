# 动作线条缩略图

v0.4.0 为全部 84 个内置动作提供 SVG 线条缩略图，在动作库、训练选择器及训练动作卡片中使用。缩略图由本项目以矢量代码绘制，包含人物姿势和相应器械，不再依赖视频海报覆盖率。

卧推、推举、深蹲、划船、弯举、俯卧撑、有氧等采用各自的姿势映射；同一运动模式的器械变式共享基础线稿，并按动作器械信息显示哑铃、杠铃、凳、滑轮等元素。图形是简化动作示意，详细要点仍由文字说明和已核验真人视频提供。

## 动画与静态显示

- 适合循环展示的动作，在缩略图进入可见范围时呈现轻量循环；离开屏幕或切到后台时停止。
- 动作库工具栏可在动态图和静态图之间切换。
- 系统开启“减少动态效果”时，全部线稿自动使用静态姿势。
- 平板支撑、侧平板支撑、Pallof 抗旋转等保持类动作默认静态显示，不人为添加反复屈伸。
- 没有内置映射的个人动作显示带明确可读标签的静态占位线稿，不根据名称猜测具体姿势。

## 离线与数据

线稿和姿势映射随应用代码打包，显示缩略图不请求第三方图片、视频文件或在线生成接口。应用完成首次离线准备后，缩略图即可离线查看；真人视频继续采用独立的按需下载策略。

这项变更不修改业务记录、历史训练快照或备份格式。稳定内置动作标识用于查找线稿，版本更新后既有记录可显示新的缩略图。

## 验证

单元测试覆盖 84 个动作的映射完整性、坐标合法性、保持类静态规则和个人动作占位。浏览器测试覆盖全部缩略图、动画/静态切换、减少动态效果、离线重开及手机训练卡片，并保留原有视频与业务流程回归。
