# 移动端适配

## 视觉方向

沿用原有黑白灰配色、细边框、紧凑列表和小圆角。手机与桌面保持同一套界面语言；首页直接显示日历、数据和记录入口。

## 操作适配

- 手机首次打开使用周视图，桌面默认月视图；链接中的周月参数优先。手机日期格用状态点展示记录，具体情况在当日卡片和日期按钮的可访问名称中查看。
- 标题下方保留简洁的餐食、体重按钮；存在训练草稿时显示继续训练。快捷记录沿用当前所选日期。
- 训练的重量、次数、时长、距离和用力程度使用可直接填写的组次卡片；完成状态采用中性色，避免横向拖动。
- 添加动作和完成训练固定在底部导航上方，正文预留空间。
- 主要触控按钮保持至少 44 像素高度，数值输入提供手机键盘提示。
- 弹窗采用小圆角底部弹层，保留可视视口高度适配、标题和保存区域、嵌套弹窗与焦点恢复。
- 深色和跟随系统模式沿用原有中性色变量。

## 验证

浏览器测试覆盖快捷记录日期、周月切换、草稿恢复、320–430 像素组次输入、底部操作与导航位置、窄屏深色弹层和焦点恢复，并回归记录、离线与备份流程。浏览器手机模拟不能替代真实 iOS/Android 的软键盘与安全区复核。

器械与动作扩充见[器械目录](equipment-catalog.md)。
