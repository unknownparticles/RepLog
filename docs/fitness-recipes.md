# 健身食谱

从饮食页的「健身食谱」或桌面资料库进入。首批 8 道：凉拌鸡丝、燕麦鸡蛋饼、牛奶燕麦配鸡蛋、蔬菜酱拌荞麦面、少油蒜蓉西兰花、清煮虾仁、嫩滑蒸蛋、葱姜清蒸鲈鱼。

支持按名称、食材搜索，按主食早餐 / 蛋白配菜 / 蔬菜分类，同时筛选每份蛋白质至少 20 克、15 分钟内、蛋奶素可选。筛选按默认一份计算，「蛋奶素可选」允许蛋和奶，不代表纯素。

详情中选择归属日期、餐次与 0.1–10 份（最多一位小数），食材和营养同时换算。浏览和取消不入账。确认后跳回目标日期饮食页，可继续编辑克重、复制或删除餐食，并在记录全天饮食后主动确认完整。

## 估算口径

上游有的菜谱存在热量前后不一致、油量不明确、整鱼与去壳重量混用等情况，因此不照搬其热量。RepLog 为上述食谱量化食材、明确油盐并调整部分做法，逐道注明差异；不因上游标题含「减脂」就认定低热量。

`recipeIngredients` 是本项目维护的通用估算表，单位为每 100 克可食部分。数值不是上游营养数据库，也未经过实验室检测。每份能量与蛋白质、碳水、脂肪分别按「食材每百克数值 × 克重 / 100」求和，能量不强制用三大营养素反算。份量先换算为 0.1 克，再按相同克重计算预览和入账，避免显示与记录口径不同。

| 口径 | 说明 |
| --- | --- |
| 肉、鱼、虾、鸡蛋 | 生重可食部分；去皮、去骨/壳，鸡蛋按去壳重 |
| 面、燕麦 | 干重，煮后的含水变化不增加营养 |
| 蔬菜 | 清洗整理后的可食生重 |
| 牛奶、油、调料 | 按克称重；所列油和酱汁按全部吃完计算 |
| 水 | 蒸蛋加入水随份量保存，其余煮制用水不作为摄入食材 |
| 配菜 | 不自动补入米饭等未列食材，也不代表完整的一餐或全天计划 |

例如凉拌鸡丝一份的鸡胸肉 200 克、芝麻油 4 克、生抽 5 克、米醋 5 克、糖 2 克与盐 0.5 克，估算能量为 287.55 千卡、蛋白质 45.405 克。品牌、酱汁剩余和烹调损耗会改变实际结果，应用明确显示「估算」。需要采用实际包装标签时，可在饮食编辑中替换相应食材。

## 数据与离线

确认入账通过单个事务创建缺少的估算食材并保存餐食，失败不留下孤立食物；重复记录不重复创建相同估算食材。已有个人编辑和归档状态保持不变，本次食谱餐食仍使用目录估算快照。食谱记录沿用既有备份、恢复和跨页面代际检查。

食谱页面与目录随生产 PWA 缓存；授权与来源说明显式加入预缓存。上游外链需联网查看，本地做法和授权可离线查看。

## 验收

运行 `npm test`、`npm run build`、`npx playwright test tests/e2e/recipes.spec.ts`。新增用例覆盖原文校验、份量与营养计算、入账原子回滚、保留用户编辑、备份恢复、筛选与空结果、指定日期与餐次、手机布局以及离线首次打开食谱并入账。

## 使用已登记食物组合

新增「健康组合餐」入口，支持从食物库组合、保存常用餐、文字匹配食物及数量。它与本文食谱通用估算分别显示：健康组合餐仅用已登记值，缺失或歧义时需确认；本文原有食谱仍明确显示通用估算。详见 [健身食物与健康组合餐](healthy-meals.md)。
