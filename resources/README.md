# 动作示范来源记录

exercise-media-sources.json 来自 2026 年 10 月 20 日对 wger 公开视频条目、动作英文名称和许可对象的核对，覆盖 29 个本地动作。作者均为 Goulart，素材许可均为 CC BY-SA 4.0。

映射使用稳定动作标识，不依赖运行时名称猜测。坐姿、曲杆、窄握等变化通过 variant 字段明确标出。

wger 动作 475 和 477 分别被标为普通引体和器械引体，但来源片段及转码结果相同，画面未清楚显示辅助方式，因此都未接入。不能仅依据数据库名称将该片段用于两种训练模式。

此文件保存来源元数据，不包含原始大视频；具体发布文件及完整署名见 public/media/exercises。
